# Change Records

Change records for this project live in this directory.

## File Naming

Use this format:

```text
YYYY-MM-DD-change-name.md
```

Example:

```text
2026-05-28-add-agent-docs.md
```

## Recommended Template

```md
# Change Title

## Summary

Briefly describe what changed.

## Files Changed

- `path/to/file`

## Verification

Describe the checks that were run, or explain why no runtime check was needed.

## Impact

Describe the expected user-facing, developer-facing, or operational impact.

## Follow-Ups

- Follow-up item, or `None`.
```

## Maintenance Rules

- Add a change record after a meaningful feature, fix, refactor, or documentation
  update.
- Keep records factual and concise.
- Do not duplicate full requirement text here; link or reference the requirement
  document when one exists.
