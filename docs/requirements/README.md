# Requirements

Requirement documents for this project live in this directory.

## File Naming

Use this format:

```text
YYYY-MM-DD-feature-name.md
```

Example:

```text
2026-05-28-login-page.md
```

## Recommended Template

```md
# Requirement Title

## Background

Describe the context and problem this requirement addresses.

## Goal

Describe the desired outcome.

## Scope

List what is included in this requirement.

## Out Of Scope

List related items that should not be implemented as part of this requirement.

## Acceptance Criteria

- Criterion 1
- Criterion 2

## Open Questions

- Question 1
```

## Maintenance Rules

- Create or update the requirement document before implementation starts.
- Keep implementation details brief unless they clarify acceptance criteria.
- Move post-implementation details to a change record in `docs/changes/`.
